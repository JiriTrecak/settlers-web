# Worldroot environment completion audit

The completed scope is the polished playable Worldroot map and its assets; this is not a claim of a universal120FPS target.

- Purchased file preserved byte-identically; SHA256 checked against original. Inventory/export names matched all38 source meshes. Loaded-GLB validation verifies triangles, finite attributes, palette colors, upright ground alignment and tree clips. Gallery inspection reviewed all21 trees,10 grasses,7 mushrooms.
- Required tree mapping confirmed from exports and map:14→primary,13→secondary;1778+889 harvestable map trees. Grass3/6 drive forest cover; dedicated editor brush and API added; eraser handles imported names. Tests verify bounded patch spacing and correct erasure.
- Original bridge,lantern,fence,road and rock kit has editable saved Blender source, deterministic recipe, packed reference and sampled palette, full-resolution comparison, individual GLBs and running studio8820. Final saved Blender validator passes. Combined live viewer and side/rear rotation inspected. Actual runtime triangle counts measured from GLB accessors, distinct from studio preview counts.
- Catalogue contains all38 vegetation assets and5 kit assets. Worldroot has969 scenery stamps and5 road strokes. Roads use generated512px material; lanterns use bounded four-light pool. Rock/fence collision declared and shared with AI. Bridge deck separate from water/terrain and excluded from construction; world render matches banks. Relevant unit tests cover transforms, light reuse, water/deck separation and route connections.
- Gameplay map tests pass for valid starts, camp routes, Root access, deterministic loot and state restoration. Ten camps and resource deposits retained. Shallow/deep-water behavior remains defined by60cm wading depth. Imported trees pass the actual TreePlayer fall, full-size sink and completion/removal test.
- Map visually inspected at forest/camp view and bridge/shore view; exported models reviewed in galleries/studio. Profiler measured native Retina scene89–101FPS with details in performance-notes.md. Geometry reduction measured; no unsupported FPS-improvement claim. Rebuild cost and remaining CPU/GPU costs documented.
- Full suite489 tests passed before the final brush addition; its2 new tests and TypeScript passed afterward. Production/wiki builds pass. Docs include source/export manifests, integration behavior, regeneration commands and explicit limitations.

Known supported limits: upright yaw-only bridge/lantern placement; vertex palette interpolation instead of original within-face texture gradients; coarse studio road preview while game terrain uses the actual texture; no guaranteed120FPS at native Retina resolution. These are documented implementation limits, not omitted map/asset deliverables.
