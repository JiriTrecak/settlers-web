# session

`Session` is one match: that map, hover/select, camera, 25ms sim accumulator. Match start `dispatch`es `placeColony` at `starts[i]` for each slot (2 when the dump has 2+ starts). Local view is `world.view(me)`. The other slot is a session `Opponent` that delay-enqueues convert + pioneer + a tower plan. First frame has fully lit HQs. The finished tower occupies a radius-40 disk; extra T1 towers from the strip extend it when they finish. Build strip picks a hut (including tower); hover shows a placement ghost (red off-land or lumberjack not level); click empty valid owned land `enqueue`s a **plan** and drops the tool. Click a pioneer or bearer to select; RMB (or LMB on empty land) commands — pioneer keeps claiming unenforced tiles toward the click, bearer `moveTo`. **C** converts bearer ↔ pioneer. Bearers haul construction goods, bricklayers hammer, a bearer occupies when it finishes. Clothing color is the local slot.

`Minimap.onLookAt` → `Camera.lookAt`. `SpeedControl.onSpeed` multiplies wall-clock dt into the accumulator (quantum stays 25ms). Space → `Renderer.fitCamera`. Escape deselects (build ghost, then claim tool, then unit, then hut highlight). Delete / Backspace `enqueue`s destroy on the highlighted hut (fog circle and occupy disk go with it on the next beat). Each frame pushes debug counts into the HUD (F3) and the current player's fog onto the minimap. F3 lists this-frame wall-clock: sim vs draw vs snapshot vs minimap, plus sim phases (flock, fog, matcher, …) summed across ticks this frame. `setShowPaths` / `setShowOwnership` / `setShowFog` are overlay toggles — stored on the session so they survive if the renderer is not up yet. Fog defaults on. F3 **claim** `enqueue`s `occupy` at the clicked cell (tower disk cheat; pioneers flip one tile).
