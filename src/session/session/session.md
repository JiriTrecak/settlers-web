# session

`Session` is one match: that map, hover/select, camera, 25ms sim accumulator. Live play stamps a local `MatchConfig`, binds one `MemoryChannel` per slot to an in-process `Room`, and only `world.tick()`s when that Room `commit`s the next beat. Click → `Lockstep.send` → confirm `through: max(tickIndex+1, elapsed+1, tickIndex+D)` with bundles at `tickIndex+1+D` (SP: D=1, in the Pixi tick; MP: also a `setInterval` so an unfocused tab still confirms). `Opponent` is another slot on the same path. Match start `dispatch`es `placeColony` per `MatchConfig` slot at tick 0 (not a wire message). Local view is `world.view(me)`. Every other slot is a session `Opponent` that thinks every ~5s: pioneer toward you, then lumberjack → sawmill → stonecutter, then extra towers from the closest T1. First frame has fully lit HQs. The garrisoned tower occupies a radius-40 disk; extra T1 towers from the strip extend it when a spare swordsman walks in. Enemy infantry assault tower doors and can flip the hut; colony HQ gone is Victory / Defeat (input stops, Exit still works). Empty selection: **Recruit** + **Build** on the bottom command row. Build lists placeable huts (icon + label + owned count). Recruit lists Swordsman (click-spawn `spawnUnit` for now). While a hut tool is armed, every owned placeable origin shows a construction pip (green→red by flatten slope); hover shows a placement ghost (red off-land or plot not level); click empty valid owned land `send`s a **plan** (predicted on the snapshot the same frame; World applies at tick+D) and drops the tool. LMB selects a pioneer or swordsman by sampling the sprite (shift+click toggles; shift-drag marquees sprite boxes). Bearers and workers are not selectable. RMB commands the group — pioneer keeps claiming unenforced tiles toward the click, swordsman `moveTo` (shift = forced). Empty LMB clears the group. **C** converts a selected pioneer → bearer. Bearers haul construction goods, bricklayers hammer, a bearer occupies when it finishes. Clothing color is the local slot.

`Minimap.onLookAt` → `Camera.lookAt`. `SpeedControl.onSpeed` multiplies wall-clock dt into the accumulator (quantum stays 25ms). Space → `Renderer.fitCamera` (replay: play/pause). Escape deselects (build ghost, then build page, then claim tool, then unit, then hut highlight). Delete / Backspace `send`s destroy on an **owned** highlighted hut (fog circle and occupy disk go with it after D). Each frame pushes debug counts into the HUD (F3) and the current player's fog, occupy rim, huts, and units onto the minimap. F3 lists this-frame wall-clock: sim vs draw vs snapshot vs minimap, plus sim phases (flock, fog, matcher, …) summed across ticks this frame. `setShowPaths` / `setShowOwnership` / `setShowFog` are overlay toggles — stored on the session so they survive if the renderer is not up yet. Fog defaults on. F3 **claim** `send`s `occupy` at the clicked cell (tower disk cheat; pioneers flip one tile). Victory/Defeat writes a replay file (`ReplayStore`); **Save replay** writes one at the current tick. Watch mode rebuilds from that log, no opponent script, no commands, no Lockstep. Timeline player dropdown retargets `world.view(slot)` (fog now; goods later) and looks at that slot's HQ.
