# session

`Session` is one match: that map, hover/select, camera, 25ms sim accumulator. Match start `dispatch`es `placeColony` at `starts[i]` for each lobby slot (clamped to the dump; default 2 when the map allows). Local view is `world.view(me)`. Every other slot is a session `Opponent` that thinks every ~5s: pioneer toward you, then lumberjack → sawmill → stonecutter, then extra towers from the closest T1. First frame has fully lit HQs. The garrisoned tower occupies a radius-40 disk; extra T1 towers from the strip extend it when a spare swordsman walks in. Enemy infantry assault tower doors and can flip the hut; colony HQ gone is Victory / Defeat (input stops, Exit still works). Build strip picks a hut (including tower); hover shows a placement ghost (red off-land or lumberjack not level); click empty valid owned land `enqueue`s a **plan** and drops the tool. Units tab is a debug T1 dump (1 / ×10 / ×100, sticky). LMB selects a pioneer or swordsman by sampling the sprite (shift+click toggles; shift-drag marquees sprite boxes). Bearers and workers are not selectable. RMB commands the group — pioneer keeps claiming unenforced tiles toward the click, swordsman `moveTo` (shift = forced). Empty LMB clears the group. **C** converts a selected pioneer → bearer. Bearers haul construction goods, bricklayers hammer, a bearer occupies when it finishes. Clothing color is the local slot.

`Minimap.onLookAt` → `Camera.lookAt`. `SpeedControl.onSpeed` multiplies wall-clock dt into the accumulator (quantum stays 25ms). Space → `Renderer.fitCamera` (replay: play/pause). Escape deselects (build ghost, then claim tool, then unit, then hut highlight). Delete / Backspace `enqueue`s destroy on an **owned** highlighted hut (fog circle and occupy disk go with it on the next beat). Each frame pushes debug counts into the HUD (F3) and the current player's fog, occupy rim, huts, and units onto the minimap. F3 lists this-frame wall-clock: sim vs draw vs snapshot vs minimap, plus sim phases (flock, fog, matcher, …) summed across ticks this frame. `setShowPaths` / `setShowOwnership` / `setShowFog` are overlay toggles — stored on the session so they survive if the renderer is not up yet. Fog defaults on. F3 **claim** `enqueue`s `occupy` at the clicked cell (tower disk cheat; pioneers flip one tile). Victory/Defeat writes a replay file (`ReplayStore`); **Save replay** writes one at the current tick. Watch mode rebuilds from that log, no opponent script, no commands. Timeline player dropdown retargets `world.view(slot)` (fog now; goods later) and looks at that slot's HQ.
