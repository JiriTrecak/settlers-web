# session

`Session` is one match: that map, hover/select, camera, 25ms sim accumulator. Match start `dispatch`es `placeColony` at `starts[i]` for each slot (2 when the dump has 2+ starts). Local view is `world.view(me)`. The other slot is a session `Opponent` that delay-enqueues convert + pioneer + a tower plan + an enlisted L1. First frame has fully lit HQs. The garrisoned tower occupies a radius-40 disk; extra T1 towers from the strip extend it when a spare swordsman walks in. Build strip picks a hut (including tower); hover shows a placement ghost (red off-land or lumberjack not level); click empty valid owned land `enqueue`s a **plan** and drops the tool. LMB selects a pioneer or swordsman by sampling the sprite (shift+click toggles; shift-drag marquees sprite boxes). Bearers and workers are not selectable. RMB commands the group — pioneer keeps claiming unenforced tiles toward the click, swordsman `moveTo` (shift = forced). Empty LMB clears the group. **C** converts a selected pioneer → bearer. Bearers haul construction goods, bricklayers hammer, a bearer occupies when it finishes. Clothing color is the local slot.

`Minimap.onLookAt` → `Camera.lookAt`. `SpeedControl.onSpeed` multiplies wall-clock dt into the accumulator (quantum stays 25ms). Space → `Renderer.fitCamera`. Escape deselects (build ghost, then claim tool, then unit, then hut highlight). Delete / Backspace `enqueue`s destroy on the highlighted hut (fog circle and occupy disk go with it on the next beat). Each frame pushes debug counts into the HUD (F3) and the current player's fog onto the minimap. F3 lists this-frame wall-clock: sim vs draw vs snapshot vs minimap, plus sim phases (flock, fog, matcher, …) summed across ticks this frame. `setShowPaths` / `setShowOwnership` / `setShowFog` are overlay toggles — stored on the session so they survive if the renderer is not up yet. Fog defaults on. F3 **claim** `enqueue`s `occupy` at the clicked cell (tower disk cheat; pioneers flip one tile).
