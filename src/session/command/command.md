# command

`CommandBoard` turns selection into a 12-slot `CommandPage`. The widget does not know lumberjack from stop.

Idle: **Recruit** (slot 10) + **Build** (slot 11). Build → `PLACEABLE` huts (icons from catalog `built` paths). Recruit → Swordsman (click-spawn `spawnUnit` for now; barracks queue later). Units / hut selected: empty grid; middle pane shows the name.

Escape: drop the place ghost, then pop the drill, then the rest of Session deselect.
