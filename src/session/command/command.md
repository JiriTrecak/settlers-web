# command

`CommandBoard` turns selection into a 12-slot `CommandPage`. The widget does not know lumberjack from stop. `CommandBoard.key` fires the enabled slot on that page whose `hotkey` matches. Idle **P** / **F** / **M** open Production / Food / Military (**B** is Production). Hut keys are page-local.

Idle: **Recruit** (slot 7) + **Tools** (slot 8) + **Production** (slot 9, P) + **Food** (slot 10, F) + **Military** (slot 11, M). Cards without a sim `kind` stay on the grid at 50% opacity and do not arm. Production: lumberjack, store (locked), sawmill, forester / coal mine (locked), iron mine, gold mine, stonecutter / iron smelter, gold smelter, toolmaker (locked). Food: farm, mill, baker, waterworks / pig farm, slaughter, fisher, winery (locked) / donkey farm (locked), house, medium house (locked). Military: tower, then locked lookout / big tower / castle / barracks / weapon smith / temples / hospital / harbor / dockyard. Recruit → Swordsman (click-spawn `spawnUnit` for now; barracks queue later) + Pioneer (**C**) + Geologist (**G**). Pioneer / geologist click converts the closest idle empty-handed bearer and sends them toward the tile (bearers are not selectable). Tools → Fewer / Digger / More and Fewer / Bricklayer / More (±1 each; badges `have → cap` while filling). Empty 0/0 hides; a plan, scaffold, inbound occupy, or blade-equip paints `have → queued` (e.g. `0 → 1`). Hut selected: **Delete** (slot 0, owned + can command) + **Area** (slot 1, outdoor huts with `workRadius` > 0) + **Cancel** (slot 11, same `page.back` as drill Back). Area arms a map click that `send`s `setWorkArea`. Middle pane lists **Needs** (construction piles while plan/scaffold, else request) and **Produces** (offer), each as icon + `have / max`. Empty lists hide. Units: empty grid; middle pane shows the name.

Escape: drop the place ghost, then pop the drill (Production / Food / Military → idle), then the rest of Session deselect.
