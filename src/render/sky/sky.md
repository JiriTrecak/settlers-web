# Sky and day cycle

`src/shared/environment/dayCycle.ts` samples four authored lighting looks from `daytimes.json`, with a separate winter day profile. The 600-second default cycle holds day for 270 seconds and night for 270 seconds, with 30-second dawn/dusk transitions through midpoint keys. Colors interpolate in linear light; HDR multipliers interpolate separately.

`Sky` maps ambient, directional sunlight, sky fill and background into Three.js. Outdoor environment presets modify these values; interiors use fixed authored lighting. Canopy and cloud animation is independent of the held lighting phases. The editor can pause and scrub the clock.

Fog uses authored density, distance onset, height onset and height dispersion. The atmosphere composite handles visibility masking, exposure/output conversion and color grading. Published original grading volumes are generated by `scripts/assets/publish-original-grades.ts`; they are asset dependencies rather than files loaded from a reference installation.

Some schema fields describe effects not applied by the renderer. Consult `lightingDiagnostics()` before treating every stored colorization or bloom value as visible behavior. Portrait lighting remains independent. See the [atmosphere contract](../../../docs/expansion/volumetric-atmosphere.md) for rendering and performance limits.
