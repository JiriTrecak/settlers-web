`MapInput` — canvas drag pan, wheel zoom, WASD. Editor passes `orbit` so Alt-LMB / MMB / RMB rotate the view. Home / Gamecam is `onHome`. Brush mode (`paint`) steals LMB for the mask; Select (`grab`) steals LMB on a stamp. Space+drag pans; Shift+wheel / Ctrl+wheel tweak the brush. Play does not orbit.
