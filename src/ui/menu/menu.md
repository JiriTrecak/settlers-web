# Menu

First screen: clean forest background, separate compact iron wordmark, five fixed-size illustrated buttons with live HTML labels. Normal and highlighted backgrounds share a sprite sheet. Chains are omitted. Settings edits the saved multiplayer name and offers fullscreen. Exit closes script-opened windows; browsers that disallow closing show a returnable message. Multiplayer opens the existing lobby; Singleplayer and Editor retain their existing routes.

Art and generation provenance: `assets/ui/main-menu/README.md`.
