# hud

In-match overlay: compact fps + cursor always on. FPS on the compact line is sampled once a second (frame count / elapsed); F3 still dumps the live EMA. F3 / ` / the F3 button expands entity counts, jobs, stacks, sim load. Overlay toggles: **fog** (default on; off = omniscient view), **paths** (walk queues), **ownership** (owned cells, player tint 50%). **claim** arms a click tool that stamps a tower-radius occupy disk. Styles in `styles.css`.

**Exit** (left of the minimap) asks before tearing the match down. Escape deselects (ghost → claim → hut); it does not leave. Speed under the minimap.
