# hud

In-match overlay: compact fps + cursor always on. F3 / ` / the F3 button expands entity counts, jobs, stacks, sim load. Overlay toggles: **paths** (walk queues), **ownership** (owned cells, player tint 50%). **claim** arms a click tool that stamps a tower-radius occupy disk. Styles in `styles.css`.

**Exit** (left of the minimap) asks before tearing the match down. Escape deselects (ghost → claim → hut); it does not leave. Speed under the minimap.
