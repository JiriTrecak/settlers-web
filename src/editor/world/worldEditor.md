# worldEditor

Gameplay objects use the Entities tool and `entityAuthoring.ts`, with explicit definition IDs, owners, initial state and camps. Spawn edits the declared setup. Entity undo/redo includes associated camps and player starts but never rewinds unrelated terrain/scenery/lighting changes. Async gameplay models trigger a fresh paint when ready. The comparison page uses the same authoring projection. See [the author reference](../../../docs/declarations/README.md).

Paints the 256² grid through the game `Renderer`. Holds the current `UtcMap`. Select picks a stamp: drag to move, Shift-drag / Q·E / R / yaw slider to rotate, Del to delete. Stamp places one asset on click (water on wet, land on dry, span anywhere; `R` yaws 90°). Brush paints a red mask; Apply scatters the kit into stamps — water slots skip dry land, land props skip water. Clean wipes stamps in a disc (Objects now; Foliage later). Sculpt Live raises / lowers; Water paints a mask and Apply cuts a basin under the sea. Owns the shared minimap. Camera is free-orbit ortho unless Gamecam is on — then WC3 perspective, two-block frame, pan to half a block past the red. `screenshot` presents then grabs the canvas (optional pose, restored unless `keep`).
