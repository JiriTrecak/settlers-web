# chrome

Editor docks. One top sheet (name + file), tools left. Select opens name + yaw; drag moves, Shift-drag rotates. Grid toggles a sibling mode dock (Tiles / Full / None). Brush opens a sibling dock: item rows (thumb + % / scale + ×), New empties the kit, named presets, size / density / Apply. Clean opens type + size; drag wipes Objects. Sculpt (after Clean) is Live (raise/lower) or Water (paint + Apply a basin). Gamecam latches the play camera. MCP (after Gamecam) opens a sibling dock: enable the Cursor bridge + port; prefs persist and reconnect on load. Asset chip bottom-left. Camera binds bottom-right. Catalogue is a modal with iso mesh snapshots (lazy, as cards scroll).
