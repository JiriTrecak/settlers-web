# world

Match sim. Owns `Clock`, `MapGrid`, `ObjectGrid`, `BuildingGrid`, `LandGrid`, `FogGrid`, `MarkGrid`, occupancy, movables, seeded rng. `dispatch(Action)` is the only mutation from outside. `tick()` is one 25ms beat: trees grow, houses spawn, professions assign, plans construct, matcher assigns `deliver`, idle flock, `tickJob` runs the verbs, newly built occupying buildings stamp land, then fog circles resize and dim. `placeBuilding` is instant-finished (colony, tests). `placePlan` / dispatch is a scaffold. `destroyBuilding` removes the hut, unstamps fog + occupy land, and kicks the worker out as a bearer. Finished occupying buildings (tower) stamp a tower-radius disk — HQ and extra T1 towers. After the first disk, placement requires owned land; `needsPlayersGround` settlers path on it; outdoor gatherers `acceptWork` on it. Occupancy skips `inside` units. Building views include `flag` (door vs occupied roof). `view(player)` includes that player's `FogView`.
