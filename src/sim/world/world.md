# world

Match sim. Owns `Clock`, `MapGrid`, `ObjectGrid`, `BuildingGrid`, `LandGrid`, `FogGrid`, `MarkGrid`, occupancy, movables, seeded rng. Play loop mutates through `enqueue(action, tick, envelope)` from a Room `commit` (envelope `player` wins; `seq` is the slot's bundle index). Tests may omit the envelope (owner inferred) and use `dispatch` for *now*. `placeColony` after tick 0 is dropped. Foreign unit / hut / `action.player` commands are no-ops. `tick()` increments the clock, applies every due action (player, then seq), then runs the sim step. Pass a `TickTimings` bucket to accumulate wall-clock per phase (session does this for F3). Applied actions append to `log()`. `checksum()` mixes tick, RNG, units (including health), huts, land owners, heightmap, landscape — not fog. `replay(log, untilTick?)` re-enqueues onto an empty world and ticks until `untilTick` (or the last logged beat). Seek-back clones the dump grid. `placeBuilding` is instant-finished (colony, tests). `placePlan` / `placeBuilding` action is a fence plan. `constructionMarks(kind, player)` lists every placeable origin on that player's land (`null` before they have an occupy disk). `destroyBuilding` removes the hut, unstamps fog + occupy land, and kicks the worker out as a bearer. HP ≤ 0 splices the unit after jobs and unstamps its fog circle. Finished occupying buildings (tower) stamp a tower-radius disk **while garrisoned** — HQ and extra T1 towers. Emptying the garrison releases it. After the first disk, placement requires owned land; a player's **first** occupying hut may still stamp virgin (unowned) tiles so a second HQ can land. Extra towers need owned land. `needsPlayersGround` settlers path on it; outdoor gatherers `acceptWork` on it. Occupancy skips `inside` units and commits after each step/job so two units cannot share a hex. Debug `spawnUnit` stamps idle swordsmen (Units strip). Enemy infantry assault tower doors; an empty broken door flips `player` (land transfers if the disk was held). Losing a colony HQ knocks that slot out; `outcome` fires when one HQ remains (winner) or none (`winner: null`). Building views include `flag` (door vs occupied roof). `view(player)` includes that player's `FogView` and `outcome`.
