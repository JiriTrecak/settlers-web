# world

Match sim. Owns `Clock`, `MapGrid`, `ObjectGrid`, `BuildingGrid`, `LandGrid`, `FogGrid`, `MarkGrid`, occupancy, movables, seeded rng. Session mutates through `enqueue(Action)` (default: next beat). `dispatch` is the test helper that applies now. `tick()` increments the clock, applies every due action (player, then enqueue seq), then runs the sim step. Applied actions append to `log()`. `checksum()` mixes tick, RNG, units, huts, land owners, objects — not fog. `replay(log)` re-enqueues onto an empty world. `placeBuilding` is instant-finished (colony, tests). `placePlan` / `placeBuilding` action is a scaffold. `destroyBuilding` removes the hut, unstamps fog + occupy land, and kicks the worker out as a bearer. Finished occupying buildings (tower) stamp a tower-radius disk — HQ and extra T1 towers. After the first disk, placement requires owned land; `needsPlayersGround` settlers path on it; outdoor gatherers `acceptWork` on it. Occupancy skips `inside` units. Building views include `flag` (door vs occupied roof). `view(player)` includes that player's `FogView`.
