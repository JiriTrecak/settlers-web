# world

Match sim. Owns `Clock`, `MapGrid`, `ObjectGrid`, `BuildingGrid`, `LandGrid`, `FogGrid`, `MarkGrid`, occupancy, movables, seeded rng. Session mutates through `enqueue(Action)` (default: next beat). `dispatch` is the test helper that applies now. `tick()` increments the clock, applies every due action (player, then enqueue seq), then runs the sim step. Pass a `TickTimings` bucket to accumulate wall-clock per phase (session does this for F3). Applied actions append to `log()`. `checksum()` mixes tick, RNG, units (including health), huts, land owners, heightmap, landscape — not fog. `replay(log)` re-enqueues onto an empty world. `placeBuilding` is instant-finished (colony, tests). `placePlan` / `placeBuilding` action is a fence plan. `destroyBuilding` removes the hut, unstamps fog + occupy land, and kicks the worker out as a bearer. HP ≤ 0 splices the unit after jobs and unstamps its fog circle. Finished occupying buildings (tower) stamp a tower-radius disk **while garrisoned** — HQ and extra T1 towers. Emptying the garrison releases it. After the first disk, placement requires owned land; a player's **first** occupying hut may still stamp virgin (unowned) tiles so a second HQ can land. Extra towers need owned land. `needsPlayersGround` settlers path on it; outdoor gatherers `acceptWork` on it. Occupancy skips `inside` units and commits after each step/job so two units cannot share a hex. Enemy infantry assault tower doors; an empty broken door flips `player` (land transfers if the disk was held). Colony HQ gone — capture or destroy — sets `outcome` (winner / defeated). Building views include `flag` (door vs occupied roof). `view(player)` includes that player's `FogView` and `outcome`.
