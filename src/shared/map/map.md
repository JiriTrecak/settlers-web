# map

Hardcoded match map. `MAP_ID` is the only playable id. `MAP_SIZE` is playable cells (square, 1 world unit per cell). Halo (`MAP_HALO` = 16) is visible but not playable. Fringe (`MAP_FRINGE` = 16) is grid-only past the halo. Major tile is 8 cells.

`utcmap.ts` is the authored file: `.utcmap` JSON. `name` is the document title. `stamps` are placed catalog assets.
