| Folder | Owns |
|---|---|
| `iso/` | Grid ↔ world pixels |
| `direction/` | Six facings, same deltas as `HEX_DELTAS` |
| `player/` | Eight clothing tints |
| `landscape/` | Landscape type union, colors, hex neighbors |
| `types/` | `GridPos`, `Action` |
