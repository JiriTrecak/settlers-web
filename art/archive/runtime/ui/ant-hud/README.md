# Ant HUD concept

`frame-concept-v1.png` is a standalone faction interface background concept, generated with built-in imagegen. Applied to the in-game command dock; live map, portrait, information and command controls align to the frame. Keep labels, portraits, minimap and icons as separate live elements.

Prompt:
Use case ui-mockup / game UI asset. Design a polished ORIGINAL ANT FACTION bottom HUD background for Under the Canopy, a mature stylized fantasy insect RTS. The visual reference in concept is the crafted faction-specific bottom interface of classic Warcraft 3, but create original insect civilization materials and shapes. Produce a wide horizontal 3:1 image of ONLY THE EMPTY INTERFACE FRAME, no gameplay screenshot. Background outside upper silhouette transparent real alpha. The interface occupies bottom 65% of canvas, generous transparent space above. Layout across the full width: left a large almost-square recessed EMPTY minimap well occupying 21% width, next a narrower upright EMPTY portrait well 12% width, center a wide quiet EMPTY information panel 37% width, right an EMPTY command panel 25% width. Modular structural separators between panels, shared continuous bottom rail, subtly uneven sculpted top rim. Right command panel has a restrained 4-column by 3-row arrangement of blank square dark recessed slots, no icons. Center completely open and dark for dynamic text and selected unit icons, no baked labels or dividers there. All wells opaque near-black cool charcoal, flat and visually quiet. Frame materials tell ANT faction story: layered reddish-brown and oxblood chitin shell plates shaped like armored thorax segments, strong dark forged blue-black iron corner caps, worn silver bevel highlights, restrained round rivets, blackened carved hardwood and root structural supports underneath. Small amber resin seam accents and a SMALL abstract ant mandible crest integrated into one structural separator; NOT a giant ant face or mascot. A few tiny deep green leaf fragments tucked into upper corners, mostly ant armor and colony craftsmanship rather than leafy elf vines. Subtle natural hex-less tunnel-carved motifs; NO honeycomb, no bee imagery, no medieval human castle ornament. Broad chunky stylized planes, excellent hand-painted dimensional fantasy game craftsmanship, warlike but appealing, matches adorable-sturdy humanoid insect warriors in heavy iron armor. Cool upper-left lighting, deep sculpted shadows, warm chitin contrast, aged silver catching edges. Keep trim relatively thin and functional, maximize usable panel space, avoid busy ornament spilling into wells. Front-facing orthographic flat UI orientation, no perspective angle, no text anywhere, no numbers, no letters, no resource icons, no game logo, no characters, no watermark. Finished production concept for reusable faction UI background, clean silhouette and crisp details.

## Steel revision

`frame-steel-v2.png` is the active, subtler steel revision, generated with built-in imagegen from v1. Prompt requested the same four-well layout, half-thickness trim, dark forged steel and worn silver bevels, tiny oxblood corner inlays, and removal of large horns, mandibles, roots, leaves and amber glow. No labels or icons. The rendered dock is capped at 1200px and centered; CSS clips the artwork's upper empty margin independently of the controls.
