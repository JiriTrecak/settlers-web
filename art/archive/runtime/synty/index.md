# synty

Converted Synty POLYGON Nature meshes. Source FBX stays in Downloads — do not commit the Unity dump.

`scripts/import-synty.ts` writes self-contained glTFs (cm → meters, vertex colors, leaf atlases embedded). Ids are `synty-*`. Lilies and reeds are type `water`; the curved bridge is `span`. Restyle later — this pack is block-in only.
