**Woodland Daisies — foliage**

- **What it is:** Original daisies with a simple silhouette and muted woodland materials.
- **Asset folder:** [woodland-daisies](.)
- **Files:** [Blender](woodland-daisies.blend), [Game GLB](../../../../assets/library/asset.models.environment.woodland-daisies/geometry.glb). The separate `model.glb` is the studio preview; the linked Game GLB is the published runtime export.
- **Live preview:** [Runtime model viewer](http://127.0.0.1:5173/experiments/woodland-review/index.html#woodland-daisies).
- **Geometry:** 240 exported triangles; 1 meshes; 3 materials. One LOD.
- **Runtime features:** Static; no animations. No team-color surfaces (neutral scenery).
- **Game integration:** Integrated into meadow, forest-floor or riverbank generators; tested in the live environment.
- **Limitations:** Deliberately simple geometry and shared painted materials. No additional interaction beyond the integration described above. Runtime lighting differs from the black-background studio setup.
