# First-screen artwork

The menu uses separate images and native HTML buttons with editable labels.

- `forest-heroes.png`: user-approved clean background, copied from the user's Downloads attachment.
- `logo-iron-wordmark.png`: existing approved-exploration silver/iron variant; replaces the dense leaf-and-root crest for readability at menu scale.
- `buttons.png`: built-in imagegen normal/highlight sprite sheet, no labels. CSS displays each state independently.
- `chain.png`: built-in imagegen separate chain asset; retained but hidden/unused at the user's request.
- `logo-metal.png`: previous leaf-and-root logo retained for reference, unused.
- `menu-concept.png`: old composite preview, unused by the live menu.

Generation mode: built-in imagegen, no CLI/API fallback.

Button prompt: Production game UI sprite asset on transparent background with real alpha. TWO identical wide slim fantasy forged metal BUTTON BACKGROUNDS stacked vertically, NO TEXT ANYWHERE. Canvas 3:2 landscape. Top half contains normal button, bottom half contains highlighted version of EXACT same button geometry, aligned precisely. Each button width 90% of canvas, height 20% of canvas, centers x50%, y25% and y75%. Transparent outside their silhouettes; button interiors are OPAQUE blue-black charcoal iron with calm faint hammered texture, blank generous center for editable text added later. Sculpted silver bevel frame with broad dark gunmetal layered angular armor plates on the ends, restrained rivets, worn bright silver edges, subtle cool forest lighting, premium stylized fantasy insect warrior armor aesthetic. Compact heroic craftsmanship, NOT filigree, no gold, no leaves, no chains, no symbols, no lettering, no background scene. Normal state muted silver; highlighted state same design with brighter cool silver bevels and very subtle pale blue interior illumination, no neon. Orthographic perfectly frontal UI graphic, not perspective. Entire silhouettes within canvas generous clear margins.

Chain prompt: Production game UI asset, transparent background with real alpha. ONE single straight vertical THIN forged iron chain, centered, running the full height from top edge to bottom edge, no end hooks. Portrait canvas narrow 1:3. Chain occupies central 25% of image width; empty transparent margins. Repeating connected elongated angular oval links alternating orientation, physically connected, dark blue-black iron with worn silver bevels, subtle hammered stylized fantasy armor craftsmanship, restrained cool light upper left. Clean consistent width and link size, orthographic front view, no perspective, no dangling branches, no decorations, no text, no ground, no background, no cast shadow outside object. Designed to be rendered as a slender 22px-wide chain behind fantasy menu buttons, crisp readable silhouette.
