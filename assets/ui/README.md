## Atlas prompt

Use case: stylized-concept. Production asset: ONE square 1024x1024 RTS game command-icon atlas, exact 4 by 4 grid of equal square tiles with NO gaps, NO labels, NO text, NO borders. Original painterly fantasy game artwork, chunky readable Warcraft-3-era hand-painted icon aesthetic, rich warm highlights, deep teal shadows, substantial sculpted forms, each subject centered on its own dark vignette backdrop. Each tile must contain one distinct icon, occupying 80 percent of its tile, readable at 64px. Row 1 left to right: lumberjack log cabin with axe and stump; sawmill timber workshop with large wooden wheel and saw; forester green-roof nursery cabin with saplings; stonemason quarry hut with pickaxe and gray stone. Row 2: cozy thatched settler house; stout stone watchtower with blue banner; majestic squat main stone fort with blue banners; friendly rugged male settler portrait with brown leather cap and blue tunic. Row 3: stack of golden sawn planks; pile of chunky gray dressed stone cubes; bundle of raw bark logs with golden cut ends; worker carrying a crate on shoulder. Row 4: curved golden return-home arrow over small house; red wax seal with an X cancellation mark; luminous sun and crescent moon on a navy circular medallion; rolled parchment map with compass. Exact uniform tile boundaries at quarters so CSS background-position can display each icon. No words, no numbers, no watermarks, no outer margins.

## Timber prompt

Use case stylized-concept. One production game UI material texture, square 1024x1024, seamless edge to edge dark aged walnut timber planks for a richly hand-painted fantasy RTS HUD. Front-on orthographic view, no perspective. Broad vertical planks, deep carved wood grain, warm worn amber edges, dark brown walnut recesses, subtle hand painted highlights, restrained material contrast to sit behind readable UI. Warcraft-era crafted fantasy aesthetic, original artwork. Entire image wood only. No icons, lettering, symbols, metal fittings, frames, empty borders, watermark, objects or scene. Even gentle ambient light. Texture should read as substantial carved timber rather than photographic flooring.
